# エントリーフォームで取得する個人情報の点検

OMATSU-RebootCAMPのエントリーフォームに、保険加入のため
**生年月日・性別・住所**を追加するにあたり、現行のプライバシーポリシー
（`src/pages/privacy.astro`）との整合を確認した結果です。

---

## 結論

**取得する項目そのものに問題はありません。ただし、現行ポリシーのままでは2点足りません。**

| # | 論点 | 判定 |
|---|---|---|
| 1 | 生年月日・性別・住所を取得すること自体 | **問題なし** |
| 2 | 保険加入という利用目的の記載 | **不足。要追記** |
| 3 | 参加自治会と共同で管理すること | **不足。要追記（法27条）** |

2と3については、**フォーム側に明示と同意チェックを実装済み**のため、
このまま運用しても直ちに違法とはなりません。ただしポリシー本体にも
書いておくのが本来の姿なので、下に改定案を用意しました。

---

## 1. 取得する項目について（問題なし）

生年月日・性別・住所は、いずれも**要配慮個人情報には該当しません**。

個人情報保護法第2条第3項の要配慮個人情報は、人種・信条・社会的身分・病歴・
犯罪の経歴・犯罪被害の事実などを指します。性別・年齢・住所はこれに含まれず、
本人同意による通常の取得で足ります。

保険加入手続きに必要な項目であり、利用目的との関連性も明確です。

## 2. 利用目的の記載が不足している

現行ポリシーの「個人情報利用目的の特定」は10項目ありますが、いずれも
寄付・助成・サービス案内が中心で、**「イベント参加者の受付」「保険の加入手続き」
が読み取れません**。

個人情報保護法第17条は利用目的をできる限り特定することを求めており、
第21条は取得時の通知・公表を求めています。取得する以上、目的を書く必要があります。

## 3. 参加自治会との共同管理が書かれていない（最重要）

「当財団と参加自治会で管理する」という運用は、法律上は**共同利用**にあたります。

第三者提供の制限（法27条）の原則では本人同意が必要ですが、同条5項3号により、
以下の4点をあらかじめ本人に通知するか、本人が容易に知り得る状態に置けば、
共同利用者は第三者に該当しないものとして扱えます。

1. 共同利用する旨
2. 共同して利用される個人データの項目
3. 共同して利用する者の範囲
4. 利用する者の利用目的および管理について責任を有する者の氏名または名称

現行ポリシーの「第三者提供の制限」7号にこの受け皿はありますが、
**実際の通知・周知が行われていない**ため、このままでは根拠として使えません。

---

## 実装済みの対応（フォーム側）

エントリーフォームの送信ボタン手前に、上記4点を満たす説明と同意チェックを設置しました。

> **個人情報の取り扱いについて**
>
> ご記入いただいた個人情報は、次の目的で利用します。
> - 本プログラムの参加受付・面談のご案内・当日のご連絡
> - 参加者を対象とする傷害保険の加入手続き
> - 受け入れ地域における参加者の受け入れ調整および緊急時の連絡
>
> この目的の範囲内で、**公益財団法人えひめ西条つながり基金と、参加先の自治会・
> お祭り運営組織が共同で利用します。** 上記以外の目的では利用せず、他の第三者へ
> 提供することはありません。管理責任は当財団が負い、開示・訂正・削除のご請求は
> 個人情報保護方針に記載の窓口で承ります。
>
> ☑ 上記の取り扱いと個人情報保護方針に同意します（必須）

応募者に届く自動返信メールにも同じ趣旨を記載しています。

これにより、本人の明示的な同意（法27条1項）と共同利用の通知（同条5項3号）の
両方の要件を満たす形になっています。

## ポリシー本体への追記案（未適用）

プライバシーポリシーは財団の正式文書のため、**適用は判断を仰ぎます。**
承認いただければすぐ反映します。

### 追記案A：利用目的に2項目を追加

「個人情報利用目的の特定」の箇条書きの末尾に追加します。

```
11. 当財団が主催・共催する事業への参加申込の受付および参加者との連絡
12. 事業参加者を対象とする保険の加入手続き
```

### 追記案B：「共同利用について」の節を新設

「第三者提供の制限」の直後に置きます。

```
共同利用について

当財団は、当財団が主催・共催する地域事業（OMATSU-RebootCAMP等）の
運営にあたり、以下のとおり個人データを共同して利用します。

・共同して利用される個人データの項目
  氏名、フリガナ、生年月日、性別、住所、電話番号、メールアドレス、
  参加希望内容、その他参加申込時にご記入いただいた事項

・共同して利用する者の範囲
  公益財団法人えひめ西条つながり基金および、参加者の受け入れを行う
  自治会・お祭り運営組織等の地域団体

・共同して利用する者の利用目的
  参加受付、参加者との連絡、保険の加入手続き、受け入れ地域における
  参加者の受け入れ調整、緊急時の連絡

・管理について責任を有する者
  公益財団法人えひめ西条つながり基金
  〒793-0030 愛媛県西条市大町1663番地
  コンプライアンス担当理事 星隈英明
```

## 運用面でお願いしたいこと

法律の要件とは別に、実務として次の2点をおすすめします。

1. **参加自治会への受け渡し方法を決めておく**
   メールに個人情報を平文で載せるより、必要最小限の項目に絞った名簿を
   その都度渡す形が安全です。保険会社への提出用と受け入れ担当者への
   共有用で、項目を分けるとなお良いです。

2. **保管期間を決めておく**
   「事業終了後〇年で廃棄」と決めておくと、開示請求や漏えい時の説明が
   しやすくなります。保険の請求期間を踏まえると3年程度が目安です。
